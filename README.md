# Using Feature Flags in a React Native Application

A React Native sample application that uses [ConfigCat's](https://configcat.com) Feature Flag Management system. The application is a login page in which the `signup` feature can be flipped on/off by using a feature flag.

## Prerequisites

To get started, you will need to [set up your environment](https://reactnative.dev/docs/set-up-your-environment) for React Native development.

### Build & Run

1. Clone this repository

2. Inside the project's folder, in a Command Prompt run:

```bash
`npm run android`
```
